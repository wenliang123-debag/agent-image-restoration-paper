- [SkillIR: Evolving Scene-Aware Skills for Agentic Image Restoration](https://arxiv.org/abs/2609.21468): Scene-aware skills and verified residual-state tool use for multi-degradation restoration.

- [PrismRestore: A Compact Restoration Toolbox for Agentic Image Restoration](https://arxiv.org/abs/2611.24915): A learned policy composes restoration actions exposed by channel modulation in a single frozen backbone.

- [RecurIR: Learning When and How to Revise Restoration Policies via Recursive Self-Improvement](https://arxiv.org/abs/2611.18006): Tests restoration rules against targeted degradation changes and verifies policy revisions before retaining them.

- [Look Before You Restore: Learning to Predict Before Acting for Agentic Image Restoration (PreActIR)](https://arxiv.org/abs/2610.20384): Predicts tool effects before execution and rolls back outputs that fail verification.

- [HarnessIR: Harnessing Multimodal Foundation Models for Universal Real-World Image Restoration](https://arxiv.org/abs/2610.10133): Gathers diagnostic evidence for a multimodal foundation model that restores the image, then checks whether further refinement is needed.

- [EORestore-Agent: Fidelity-Guided Agentic Restoration of Remote Sensing Images with Composite Degradations](https://arxiv.org/abs/2610.06196): Detects residual degradations and uses reference-free quality predictions to decide which remote-sensing restoration steps to keep.
