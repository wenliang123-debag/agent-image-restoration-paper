# Source Verification Log · 2026-10-25

This review checked 46 paper entries against public primary sources. The log distinguishes accessible full text, official indexes, and checks that could not be completed. Preprints are dated to the year they were first made public; formal publication labels reflect the available source evidence. This log does not claim that every external link or full text passed verification.

This review corrected titles including Q-Agent, PhotoAgent, and FaithEyes, and corrected the first authors of TIR-Agent (Guoli Jia), RetouchIQ (Qiucheng Wu), and VTool-R1 (Mingyuan Wu). ARTIE was relabeled as a submission. SkillIR was added because its public arXiv manuscript describes tool use and scene-aware skills within the scope of agentic restoration. No private manuscripts were used.

The catalog contains 46 papers: 45 existing entries and one added public preprint. No papers from adjacent fields were added to reach a target count. The full-text link for EvoIR-Agent was updated to the latest version; the link to the older figure was retained because it points to the corresponding version of that figure.

## Pending Checks and Limitations

- OpenReview verification restrictions still prevent independent checks of ARTIE's final decision and full author page. It is not labeled as accepted or rejected on that basis.
- SEAR's ECCV label follows the repository owner's confirmation in public PR #2. An independent official publication link was not obtained in this review.
- For some CVF, IEEE, and ScienceDirect pages, information was available only through official indexes. Failure to access the full text was not treated as evidence of a broken link. Affected entries are marked individually.
- This review did not download all papers, request each externally hosted figure, or run the authors' models. External URLs may change later.

The workflows, scripts, tests, candidate queue, and automation documentation deliberately removed in PR #2 remained deleted. This review changed only the README and added the manual maintenance guide and source verification log. It did not add CI or scheduled tasks.
